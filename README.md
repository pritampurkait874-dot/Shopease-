# ShopEase 🛍️

A simple, responsive online shopping website built with HTML, CSS, and JavaScript.

## Features

- 🏠 **Homepage** with hero section
- 🔍 **Search functionality** to find products
- 📂 **Category filtering** (Electronics, Fashion, Shoes, Accessories)
- 🛒 **Shopping cart** to add and view items
- 📱 **Responsive design** that works on mobile and desktop
- ⭐ **Product ratings** and pricing

## How to Use

1. Open `index.html` in your browser
2. Browse products or use the search bar
3. Filter by categories
4. Click "Add to Cart" to add items
5. Click the cart icon to view your items and total price
